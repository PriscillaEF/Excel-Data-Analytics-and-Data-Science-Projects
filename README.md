# Advanced Excel Data Science & Analytics Portfolio

Welcome to my repository of professional Excel projects. This collection highlights advanced data wrangling, interactive executive dashboards, financial/predictive modeling, statistical analysis, master-level formula logic, and robust data visualizations implemented entirely within Microsoft Excel.

---

## Repository Structure & Project Directory

### 1. Data Cleaning & Pipelines (`01-data-cleaning-and-pipelines/`)
Focuses on transforming raw, unformatted, or "dirty" datasets into clean, structured, and analysis-ready formats using Power Query, structural wrangling, and text/data parsing techniques.
* **[Data Cleaning Excel.xlsx](01-data-cleaning-and-pipelines/Data%20Cleaning%20Excel.xlsx)**: Practical exercises on handling missing values and standardizing inputs.
* **[Data Cleaning.xlsx](01-data-cleaning-and-pipelines/Data%20Cleaning.xlsx)**: Core workbook demonstrating data transformation and anomaly correction.
* **[marketing_campaign_dataset - Dirty (CLEANED).xlsx](01-data-cleaning-and-pipelines/marketing_campaign_dataset%20-%20Dirty%20(CLEANED).xlsx)**: End-to-end cleaning pipeline applied to a large-scale marketing campaign dataset.
* **[Safari Dataset.xlsx](01-data-cleaning-and-pipelines/Safari%20Dataset.xlsx)**: Raw dataset prepared and processed through systematic data cleaning workflows.

### 2. Dashboards & Business Models (`02-dashboards-and-business-models/`)
Features dynamic, stakeholder-ready executive dashboards and operational financial models utilizing Pivot Tables, Slicers, core lookup logic, and custom layout design.
* **[FlexTrade.xlsx](02-dashboards-and-business-models/FlexTrade.xlsx)**: Complex operational trading and financial dataset model.
* **[HR Metric.xlsx](02-dashboards-and-business-models/HR%20Metric.xlsx)**: Human resources analytics workbook tracking headcount, turnover rates, and demographics.
* **[SALES PERFORMANCE DASHBOARD.xlsx](02-dashboards-and-business-models/SALES%20PERFORMANCE%20DASHBOARD.xlsx)**: Comprehensive sales pipeline and quota-tracking sheet with automated visual summaries.
* **[SHOPSPHERE DASHBOARD.xlsx](02-dashboards-and-business-models/SHOPSPHERE%20DASHBOARD.xlsx)**: E-commerce retail dashboard tracking key performance indicators (KPIs) and regional trends.

### 3. Forecasting & Regression (`03-forecasting-and-regression/`)
Demonstrates predictive analytics, time-series forecasting, and statistical modeling to project future business metrics and evaluate variable relationships.
* **[Forecasting with Excel.xlsx](03-forecasting-and-regression/Forecasting%20with%20Excel.xlsx)**: Time-series revenue and trend forecasting models using built-in analysis tools.
* **[Linear Regression - excercise.xlsx](03-forecasting-and-regression/Linear%20Regression%20-%20excercise.xlsx)**: Simple and multiple linear regression exercises evaluating coefficients, R-squared values, and residuals.
* **[Predictive Analytics and Forecasting in Excel.xlsx](03-forecasting-and-regression/Predictive%20Analytics%20and%20Forecasting%20in%20Excel.xlsx)**: Implementation of trend analysis and smoothing models.

### 4. Statistical Analysis, Formulas & Visualizations (`04-statistical-analysis-and-visualizations/`)
Covers exploratory data analysis (EDA), statistical distributions, custom chart visualizations, and master-level spreadsheet formula logic.
* **[Categorical Variable Visualization.xlsx](04-statistical-analysis-and-visualizations/Categorical%20Variable%20Visualization.xlsx)**: Dedicated workbook highlighting bar charts, categorical distributions, and conditional formatting heatmaps.
* **[Data visualization.xlsx](04-statistical-analysis-and-visualizations/Data%20visualization.xlsx)**: Multi-sheet workbook showcasing advanced data presentation layouts.
* **[Eonnect Dataset.xlsx](04-statistical-analysis-and-visualizations/Eonnect%20Dataset.xlsx)**: Practical workbook demonstrating complex Excel formula mechanics (`INDEX/MATCH`, `VLOOKUP`, `AGGREGATE`, `IF`, and `IFS`).
* **[Excercise on distribution.xlsx](04-statistical-analysis-and-visualizations/Excercise%20on%20distribution.xlsx)**: Analysis of normal, binomial, and skewed statistical distributions.
* **[Numerical Variable Visualization1.xlsx](04-statistical-analysis-and-visualizations/Numerical%20Variable%20Visualization1.xlsx)**: Workbooks focusing on histograms, box plots, and continuous variable plotting.
* **[Statistics for Data Science.xlsx](04-statistical-analysis-and-visualizations/Statistics%20for%20Data%20Science.xlsx)**: Core statistical calculations including central tendency, variance, and probability distributions.

## Tools & Technologies Used
* **Microsoft Excel**: Pivot Tables, Pivot Charts, Slicers, and Timelines.
* **Advanced Formulas**: `INDEX/MATCH`, `VLOOKUP`, `AGGREGATE`, nested `IF`/`IFS`, and dynamic arrays.
* **Data Automation**: Power Query (Get & Transform) for repeatable ETL workflows.
* **Analysis ToolPak**: Descriptive statistics and regression toolkits.
